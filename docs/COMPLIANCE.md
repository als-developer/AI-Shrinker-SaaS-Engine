# Compliance Documentation

## GDPR Compliance

### Data Processing
- Purpose: AI verification and payment processing
- Legal basis: Contract performance, legitimate interest
- Data retention: 90 days for logs, 7 years for transactions

### User Rights
- Right to access: Data export API
- Right to deletion: Account deletion endpoint
- Right to rectification: Profile update endpoint

### Data Protection Measures
- Encryption at rest and in transit
- PII redaction at edge
- Access controls and audit logging

## HIPAA Compliance (Enterprise)
- BAA available upon request
- PHI encryption
- Access logs and monitoring
