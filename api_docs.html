Introduction

The Sovereign Grid API provides programmatic access to three powerful engines: AI fact-checking, micropayment processing, and model compression. All endpoints are accessible via HTTPS and require an API key.

📍 Base URL: https://api.sovereigngrid.com/v1

Authentication

All API requests must include your API key in the X-Sovereign-Key header.

curl -X POST https://api.sovereigngrid.com/v1/sovereign/execute \
  -H "Content-Type: application/json" \
  -H "X-Sovereign-Key: YOUR_API_KEY"

⚠️ Never share your API key or commit it to public repositories.

POST

TruthEngine - Fact Check

Verify claims and statements against trusted knowledge sources. Returns verdict, confidence score, and supporting sources.

// Request
{ "user_id": "your_user_id",
"execution_mode": "fact_check",
"text_payload": "The Earth revolves around the Sun."
}
// Response
{ "status": "success",
"verdict": "VERIFIED_TRUE",
"confidence": 98.5,
"sources": ["NASA", "Scientific Consensus"]
}

Error Codes

401 Unauthorized Missing or invalid API key
402 Payment Required Insufficient credits
429 Too Many Requests Rate limit exceeded

Python SDK

# Installation
pip install sovereign-grid-sdk

# Usage
from sovereign_grid import SovereignClient

client = SovereignClient(api_key="YOUR_API_KEY")
result = client.fact_check("The sky is blue")
print(result.verdict)
